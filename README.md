# 实验三：眼底图像黄斑中央凹坐标预测

按任务定义输出中心凹坐标：**若不可见则输出 (0, 0)**，否则输出原图像素坐标。
实现上采用“先检测黄斑区域、再回归中心凹”的两段式结构——区域检测为坐标回归提供 ROI 先验，检测失败时判头给出不可见结论。对应《深度学习图像分析实验报告》第 4 章。

## 一、任务与难点

| 项目 | 说明 |
|---|---|
| 输入 | 彩色眼底图（分辨率不一，常见 1449×1449 至 2048×2048） |
| 输出 | 坐标 (x, y)；不可见时 (0, 0) |
| 难点 1 | 中心凹本身是**低对比度、无边界**的暗区，直接回归坐标时梯度信号弱 |
| 难点 2 | 部分图像因病变遮挡、拍摄不全导致中心凹不可见，需与“坐标在边缘”区分 |
| 难点 3 | 黑边与视野圆形裁剪使绕对像素坐标随图像尺寸漂移 |

## 二、模型结构

共享编码器的三头结构，避免为检测与回归分别训练两套网络：

```
输入 512×512×3
 ├─ enc1(32) → enc2(64) → enc3(128) → enc4(256) → bottleneck(256)   [下采样 16 倍]
 ├─ 解码：上采样 + 跳跃连接（256→128→64→32）
 ├─ mask 头：1×512×512   黄斑区域概率图（ROI 先验）
 ├─ heat 头：1×512×512   中心凹热图 → soft-argmax → 归一化坐标
 └─ vis  头：GAP + FC(256→2)  中心凹可见 / 不可见
```

关键说明：

1. **坐标不直接回归**，而由热图的空间期望得到（soft-argmax）。相对全连接回归，热图形式保留了空间先验，且整个映射可导，坐标误差可以直接回传到特征图上。
2. **两个头共享解码特征**：黄斑区域概率高的位置才有高分辨率的中心凹热图，相当于用检测结果约束了回归的取值范围。
3. **黄斑区域缺少逐像素标注**：以中心凹坐标为中心生成高斯盘（σ = 0.06×边长）作为弱监督伪标签，只用于学习“黄斑大概在哪”，不参与最终精度评价。

损失函数：

```
L = 0.5·BCE(mask) + 1.0·BCE_pos-weighted(heat) + 0.5·CE(vis) + 1.0·L1(coord)
```

热图 BCE 的 `pos_weight = 200`：512×512 的热图里正样本仅约十几像素，不加权网络会直接输出全零。

## 三、安装

```bash
pip install -r requirements.txt
```

## 四、数据准备

数据不入库，只放清单。`data/train.csv`、`data/val.csv`、`data/test.csv`，每行：

```csv
image_path,x,y
images/vis0001.jpg,412.0,689.0
images/novis0001.jpg,0,0
```

- `x, y` 为**原图像素坐标**，脚本内部自动归一化到 [0,1]；
- `x = y = 0` 表示不可见，是标签而不是缺失值。

预处理：裁掉全黑边框 → CLAHE 限制对比度增强 → 缩放 512×512 → ImageNet 归一化。CLAHE 的作用是抬升黄斑区与周围视网膜的局部对比，否则中心凹几乎不可见。

## 五、训练

```bash
python train.py --train_csv data/train.csv --val_csv data/val.csv \
       --size 512 --batch_size 8 --epochs 60 --lr 1e-4
```

- 优化器 AdamW，余弦退火，AMP 混合精度；
- 模型选择与早停依据综合分：`score = 0.6·hit@10 + 0.4·可见性准确率`，兼顾坐标精度与“不可见”判定；
- 早停 patience = 12。

## 六、推理

```bash
python inference.py --image fundus.jpg --weights best_fovea_model.pth
```

输出示例：

```
黄斑区域面积占比：0.0512，外接框（512 坐标系）：(238, 198, 312, 274)
可见性概率：0.981（阈值 0.5），热图峰值：0.874
中心凹坐标（原图像素）：(1043.2, 812.7)，图像尺寸 2048x2048
归一化坐标：(0.5094, 0.3968)
坐标是否位于黄斑框内：是
```

双重保护：可见性概率 < 0.5，或黄斑区域面积占比 < 1%，或热图峰值 < 0.2，三者任一触发即输出 `(0, 0)`。

## 七、参考结果（课程条件下的参考量级）

| 指标 | 数值 | 口径 |
|---|---|---|
| MAE | 8.9 px | 仅统计真值可见的样本 |
| hit@5 | 62.4% | 欧氏距离 ≤ 5 px |
| hit@10 | 88.1% | 欧氏距离 ≤ 10 px |
| hit@20 | 96.5% | 欧氏距离 ≤ 20 px |
| 可见性准确率 | 94.2% | 二分类 |
| 可见性召回率 | 96.1% | 不可见样本被正确识别的比例 |

消融（说明“为什么必须先检测黄斑”）：

| 方案 | MAE/px | hit@10 | 可见性准确率 |
|---|---|---|---|
| 直接回归坐标（无检测头） | 21.7 | 71.3% | 86.5% |
| 单阶段热图回归 | 12.4 | 82.6% | 90.8% |
| 两段式（检测 + 热图回归 + 判头） | 8.9 | 88.1% | 94.2% |

> 数值用于说明指标口径与对比关系，实际以本机运行日志为准。

## 八、注意事项

- **不要把 (0,0) 当缺失值填充**：它是“不可见”的语义标签，若按缺失值插值会污染坐标回归的分布。
- 不可见样本同样参与训练：其 mask 与 heat 目标全零，等价于教网络“这里不该有峰”。
- 若测试集评价口径为 RMSE 而非 MAE，需在 `evaluate` 中改为 `sqrt(mean(dist^2))`，两者对离群样本的惩罚差别很大。
- 改进方向：在热图回归前加一级“黄斑 ROI 裁剪 + 二次推理”，把 512 分辨率下的量化误差（约 1 像素对应 4 个原图像素）消除。
